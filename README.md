# Sault

Sault is a personal mobile app for securely storing and managing private information in one place. It is designed to work offline, keeping personal data stored locally on the device.

**Status:** Personal Use / In Development

## Download

The latest Android APK is available in the repository releases/files.

Download the APK and install it directly on your Android device.

> Sault is currently intended for personal use and is not publicly distributed.

## Features

* Offline-first personal storage
* Organize information into folders
* Store account and personal records
* Search stored information
* Copy stored values quickly
* Optional TOTP support
* Journal functionality
* Local data storage
* Import and export data
* Dark-themed mobile interface

## Privacy

Sault is designed with privacy in mind.

* No account required
* No cloud synchronization
* Data is stored locally on the device
* No social features
* No dependency on an online database

## Tech Stack

* TypeScript
* React Native
* Expo
* Expo Go
* SQLite

## Project Status

Sault is currently in development and is being used as a personal application.

Features and the interface may change as development continues.
